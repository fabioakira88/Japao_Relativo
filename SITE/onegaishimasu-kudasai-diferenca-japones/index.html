お願いします vs ください: quando usar cada um no japonês cotidiano

Os dois pedem algo, mas não fazem o mesmo trabalho dentro da frase.

お願いします e ください aparecem o tempo todo, mas não são iguais. De forma simples: お願いします combina muito bem com pedidos de serviço ou substantivos; ください acompanha coisas ou ações mais diretas.

Use お願いします para serviço

  • これをお願いします。
    Kore o onegai shimasu.
    Este aqui, por favor.
  • 予約をお願いします。
    Yoyaku o onegai shimasu.
    Gostaria de fazer uma reserva.
  • 確認をお願いします。
    Kakunin o onegai shimasu.
    Por favor, confira.

Use ください para ação

  • 少し待ってください。
    Sukoshi matte kudasai.
    Por favor, espere um pouco.
  • ここに書いてください。
    Koko ni kaite kudasai.
    Por favor, escreva aqui.
  • これをください。
    Kore o kudasai.
    Me dê este, por favor.

Regra prática

Se você está pedindo que alguém execute um serviço, お願いします soa natural. Se está pedindo uma ação específica com verbo na forma て, use 〜てください.
