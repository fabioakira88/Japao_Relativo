すみません: a palavra-chave para abrir conversas no Japão

Desculpa, licença, obrigado e pedido de atenção: uma palavra resolve mais do que parece.

すみません é uma das palavras mais úteis para quem vive no Japão. Ela pode significar desculpa, com licença, obrigado pelo trabalho e também servir para chamar alguém com educação.

Usos principais

  • すみません。
    Sumimasen.
    Com licença / desculpe.
  • すみません、ちょっと聞きたいです。
    Sumimasen, chotto kikitai desu.
    Com licença, quero perguntar uma coisa.
  • すみません、お願いします。
    Sumimasen, onegai shimasu.
    Desculpe o incômodo, por favor.

Por que funciona

No Japão, iniciar direto com a pergunta pode soar brusco. すみません cria uma pequena almofada social antes do pedido. Não é submissão; é sinalizar que você reconhece o espaço do outro.

Erro comum

Não use só ごめんなさい para tudo. ごめんなさい é mais pessoal e ligado a desculpa. Para balcão, loja, rua e atendimento, すみません costuma funcionar melhor.
